### AddComponentPostInit("playercontroller")
```lua
-- 此处包装 GetActionButtonAction，对锁定目标直接返回 nil（不走向物品，不发送请求）
AddComponentPostInit('playercontroller', function(self)
	local old_fn = self.GetActionButtonAction
	self.GetActionButtonAction = function(s, force_target)
		local act = old_fn(s, force_target)
		if act ~= nil and act.action == GLOBAL.ACTIONS.PICKUP
			and act.target ~= nil
			and act.target.replica.fln_owner_lock
			and not act.target.replica.fln_owner_lock:IsAllowed(s.inst) then
			return nil
		end
		return act
```

## 四、复刻要点与风险提示

1. 该 MOD 使用了 32 处 `net_*` 网络变量，复刻时必须保证在 `inst.entity:AddNetwork()` 之后、`SetPristine()` 之前完成初始化，否则客户端实体不同步。
2. 注册了 7 处 RPC，客户端调用前必须做 `UserToPlayer` 与权限校验，避免被构造参数越权。
3. 与改动同一目标的其它 MOD 有冲突风险，接入前先跑一遍钩子目标对照。
