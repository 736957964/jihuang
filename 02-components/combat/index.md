# 战斗相关组件

| 组件名 | 文件 | 说明 |
|--------|------|------|
| `combat` | combat.lua | 战斗系统核心，攻击/伤害/目标管理 |
| `health` | health.lua | 生命值管理 |
| `weapon` | weapon.lua | 武器属性（伤害/范围/投射物） |
| `armor` | armor.lua | 防具属性（吸收率/耐久/弱点） |
| `combat_replica` | combat_replica.lua | 客户端战斗同步 |
| `aoeweapon_base` | aoeweapon_base.lua | AOE武器基类 |
| `aoeweapon_leap` | aoeweapon_leap.lua | 跳跃AOE武器 |
| `aoeweapon_lunge` | aoeweapon_lunge.lua | 冲刺AOE武器 |
| `aoeweapon_mace` | aoeweapon_mace.lua | 锤类AOE武器 |
| `attackdodger` | attackdodger.lua | 闪避能力 |
| `damagereflect` | damagereflect.lua | 反伤效果 |
| `damagetypebonus` | damagetypebonus.lua | 伤害类型加成 |
| `damagetyperesist` | damagetyperesist.lua | 伤害类型抗性 |
| `electricattacks` | electricattacks.lua | 电击攻击能力 |
| `projectile` | projectile.lua | 投射物（飞行道具） |
| `complexprojectile` | complexprojectile.lua | 复杂投射物 |
| `spdamageutil` | spdamageutil.lua | 特殊伤害工具 |
