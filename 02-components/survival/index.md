# 生存相关组件

| 组件名 | 文件 | 说明 |
|--------|------|------|
| `hunger` | hunger.lua | 饥饿值管理 |
| `sanity` | sanity.lua | 理智值管理（含疯狂/启蒙模式） |
| `temperature` | temperature.lua | 体温管理 |
| `moisture` | moisture.lua | 湿度管理 |
| `age` | age.lua | 年龄/寿命 |
| `beaverness` | beaverness.lua | 海狸值（伍迪） |
| `eater` | eater.lua | 进食能力 |
| `grogginess` | grogginess.lua | 眩晕值 |
| `sleeper` | sleeper.lua | 睡眠能力 |
| `health` | health.lua | 生命值（也在 combat 分类中） |
